# CONTEXT.md

## Project name
cpp-finance-zero-to-hero

## Project purpose
Take me from non-technical to employable-level C++ for quantitative finance
(pricing, risk, time-series, basic HFT plumbing) using project-based learning
with measurable outcomes at each stage.

## What we are building
A 16-week curriculum I work through inside this folder. Every week produces
a runnable artifact (a pricer, a backtester, a market-data parser, etc.) plus
a written reflection. Claude is my coach, code reviewer, and curriculum designer.

## Who it is for
- Me: zero coding background, finance-curious, mathematically comfortable
  through undergrad calculus and probability.
- Time available: 8 hours/week.

## What success looks like
- Week 4: I can write, compile, and debug a Black-Scholes pricer from scratch.
- Week 8: I can build a Monte Carlo VaR model on real historical data.
- Week 12: I can implement an order-book replay backtester.
- Week 16: I have 3 portfolio projects on GitHub I could show in an interview.
- Throughout: I can explain WHY each line exists, not just paste code.

## Current priorities
1. Complete Week 5 — memory model, pointers vs. references, first RNG harness.
2. Reach Milestone 2 (Week 8) — Monte Carlo VaR model on real historical data.
3. Keep spaced-retrieval cadence: re-test W1–W4 concepts at scheduled intervals alongside new material.

## What to avoid
- Tutorials that have me copy-paste without understanding.
- Toy problems with no finance context.
- Skipping the math — I want to derive, not memorize.
- "Learn everything about C++" — I only need the subset finance uses.

## Pedagogical commitments (non-negotiable)
- Every concept introduced must be tested via retrieval practice within 48 hours.
- Every project must have an automated check that proves it works.
- Every week ends with a 10-min retrospective in templates/retrospective-template.md.
- Claude must NOT hand me code I haven't first attempted myself.
