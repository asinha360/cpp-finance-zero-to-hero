## Concepts reinforced

- **Member vs local variable lifetime**: a local reconstructed each call resets all state; a member persists for the object's lifetime.
- **RNG state continuity**: two calls on the same `MCPricer` now produce independent path batches (paths 1–N, then N+1–2N) rather than the same N paths twice.
- **Redundant member storage**: if a value is only needed to forward to a sub-object's constructor, store it in the sub-object — not again in the parent.
- **`reserve()` rationale**: vector growth by reallocation copies all elements; `reserve` pays once upfront when final size is known.
