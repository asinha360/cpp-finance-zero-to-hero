## Concept detail: bond pricer re-implementation errors

**Error 1: used `r` in denominator instead of `y`.**
The coupon rate `r` determines the payment size. The yield `y` is what discounts those payments to present value. In the denominator `(1+?)^i`, the correct variable is `y`. Using `r` would price the bond by discounting at the wrong rate. This is the r vs y distinction from W2 D1 — required one prompt to trigger the correction.

**Error 2: sum lower bound at `i=2`.**
Coupons are paid at periods 1 through n. The sum must start at `i=1`, not `i=2`. Starting at `i=2` drops the first coupon from the price. Required one prompt to catch.

**Both errors represent formula recall rather than conceptual gaps** — the underlying logic was understood; the specific details needed a single cue.

## Concept detail: log return additivity

Full derivation by end of session:

```
ln(P1/P0) + ln(P2/P1) + ln(P3/P2)
= ln(P1) - ln(P0) + ln(P2) - ln(P1) + ln(P3) - ln(P2)
= ln(P3) - ln(P0)
= ln(P3/P0)
```

Intermediate prices cancel. The sum of log returns equals the log return over the full period. This means log returns can be summed over time to get total return — arithmetic returns cannot.

The cancellation step (intermediate P₁ terms cancelling) was derived after one prompt. By end of session the full chain was clean.
