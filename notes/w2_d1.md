## Concepts covered

**Coupon bond pricing.** A bond pays a fixed coupon C at each period i=1..n, and returns the face value F at maturity n. Each cashflow is discounted to present value. Total price:

```
P = Σ(i=1 to n) C/(1+y)^i  +  F/(1+y)^n
```

where y is the yield (discount rate), not r (coupon rate). This distinction — r vs y — was introduced here and tested in subsequent sessions.

**r vs y distinction (introduced):**
- r = coupon rate — determines the coupon payment C = r × F
- y = yield / market discount rate — determines what investors pay for the bond today
- A bond prices to par (P = F) when y = r; below par when y > r; above par when y < r.

**Function structure introduced:**
- `double couponPV(double C, double y, int i)` — PV of one coupon payment
- `double facePV(double F, double y, int n)` — PV of face value at maturity
- Missing `double` return type caught with coaching: function declared without a return type keyword.

**Integer division trap:** In C++, dividing two integers gives an integer result (truncated). `7 / 2 = 3`, not `3.5`. Using `int` for financial calculations causes silent precision loss. Inputs typed as `double` to avoid this.

**Assignment-too-late pattern:** Declaring a variable and assigning it on a separate line, but using it between declaration and assignment. The value at use time is garbage. Introduced as a pattern to watch for.
