## Implementation: rng_harness.cpp

Artifact: [projects/week05/rng_harness.cpp](../projects/week05/rng_harness.cpp)

### What was built
- `rand_vector()`: `mt19937` engine with hardcoded seed 123, `normal_distribution<double>(0.0, 1.0)`, fills 1M samples into a `std::vector<double>`.
- `mean()`, `sample_variance()` (Bessel's n−1), `standard_deviation()` — reused from W3 pattern, applied independently.
- `main()`: calls all three, asserts both acceptance criteria, prints result.

### Bugs caught and fixed
1. `dist(sample)` instead of `dist(engine)` in loop — self-diagnosed: `dist` needs an engine (RNG), not a `double`. Fixed independently after one coaching question.
2. Used `rd()` (non-reproducible) instead of hardcoded seed — identified after observing different output on second run; fixed to seed `123`.
3. Missing `#include <vector>` — flagged in review; compiled by luck via transitive include in `<random>`.
4. `(int)random_vector.size() <= 0` guard in `mean()` — replaced with `random_vector.empty()` after one hint.
5. `(int)random_vector.size() <= 1` cast in `sample_variance()` — removed cast; `size_t <= 1` is safe.
