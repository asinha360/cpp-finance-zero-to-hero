## Code work

### log_returns function (written from scratch)

**Bugs caught during implementation:**

| Bug | Description | How caught |
|---|---|---|
| Range-for used to index into vector | `for (const double& i : price_vec)` then `price_vec[i+1]` — `i` is the price value, not an index | Asked: "what does `i` actually contain in a range-for loop?" |
| Comma instead of semicolon in for-loop header | `for (int i = 0; i < size(), i++)` — comma vs semicolon | Pointed out directly |
| Off-by-one: went the wrong direction | Changed `< size()` to `< size() + 1` — made it worse | Trace with 5-element example: last valid i is size-2, so condition must be `< size() - 1` |
| Missing `&` in parameter | `const std::vector<double> price_vec` copies the whole vector | Pointed out directly |

Final correct implementation:
```cpp
std::vector<double> log_returns(const std::vector<double>& price_vec){
    std::vector<double> returns_vec {};
    for (int i = 0; i < static_cast<int>(price_vec.size()) - 1; i++){
        returns_vec.push_back(std::log(price_vec[i+1] / price_vec[i]));
    }
    return returns_vec;
}
```
