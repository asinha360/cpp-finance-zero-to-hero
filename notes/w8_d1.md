### 2. VaR concept derivation (three methods from first principles)

VaR (Value at Risk) — the loss threshold such that losses exceed it only X% of the time. 95% VaR means losses exceed the threshold on 5% of days.

**Historical simulation**
- No distribution assumption. Sort the actual historical log returns (log return = ln(P_t / P_{t-1}) — the continuously compounded daily return). Find the value at the 5th percentile of the sorted list.
- New C++ needed: `std::sort` + index at position `floor(0.05 * N)`.
- Weakness discussed: bounded by what actually happened in the sample window. At 99% VaR with 500 observations, only 5 data points fall in the tail — the estimate is highly sensitive to those 5 values.

**Parametric (Gaussian)**
- Fit a normal distribution to historical log returns: compute sample mean μ and sample stdev σ. Find the 5th percentile analytically: `μ + (−1.645) × σ` for 95% VaR.
- New C++ needed: the z-score constant (−1.645 for 95%, −2.326 for 99%). No simulation, no `NormalSampler`.
- Weakness: assumes returns are normally distributed. Real equity returns have fat tails — extreme events occur more often than a normal distribution predicts. Consequence: parametric VaR *understates* tail risk (too low at 99%), which is the dangerous direction to be wrong.

**Monte Carlo**
- Fit μ and σ from historical data. Simulate N = 100,000 one-day returns from N(μ, σ) using `NormalSampler` (from W6). Sort the simulated returns and index at 5%.
- New C++ needed: same sort + index operation as historical, applied to simulated data.
- Same fat-tail limitation as parametric since it draws from a normal distribution. More flexible than parametric (the distribution can be swapped to a fat-tailed one later).

### 3. Percentile index arithmetic

- 95% VaR on 500 observations: 5% × 500 = 25 observations in the left tail. Index = 24 (0-indexed). `returns[24]` is the threshold — 25 values are at or below it.
- 99% VaR: 1% × 500 = 5 observations. Index = 4. `returns[4]`.
- General formula: `returns[static_cast<int>(0.05 * N)]` for 95%, `returns[static_cast<int>(0.01 * N)]` for 99%.
