### W7 Acceptance Test

**Objective:** Run csv_loader on a 1000-row price CSV and verify that computed mean log-return and stdev match a Python reference to within 1e-6 (absolute). *Log return* = ln(price[i+1] / price[i]) — a measure of proportional price change on a log scale; additive across time periods.

**Solo attempt?** No — user had no Python script and no 1000-row CSV. Claude generated both: `generate_csv.py` (produces 1000 GBM price rows + 3 BADROW entries, saves to data/prices.csv) and `reference.py` (reads the same CSV, computes mean and stdev of log returns using Python stdlib math, prints to 10 decimal places). Day 5 is acceptance-test day, not a coding day; generating test scaffolding is appropriate.

**Results:**
- Python reference: mean −0.0002777862, stdev 0.0152992231
- C++ csv_loader: mean −0.000277786, stdev 0.0152992 (displayed at default cout precision, 6 sig figs)
- Agreement: <1e-8 (inferred from matching significant figures) — criterion 1e-6 passed.
- BADROW handling: 3 malformed rows caught and reported to stderr; errors.txt confirmed all three.
- 1000 rows loaded; 999 log returns computed.

**Implementation quality note:** csv_loader prints every loaded row to stdout (1000 lines). Noisy but not wrong. For W8, if the output becomes unwieldy, consider suppressing the per-row print or moving it behind a verbose flag. Not a blocking issue.

**What was wrong:** The "distance past K" precision is correct and represents progress from prior sessions. However, the answer does not explain *why* σ benefits the call specifically. It describes the payoff structure but not the asymmetry mechanism — i.e., it does not say that σ widens *both* tails while the payoff floor at zero neutralizes all below-K outcomes.

**What was said:** "That's 1.5/2 — 'distance past K' is the right precision. But you stopped one step short. σ widens the distribution symmetrically — it pushes more paths above K *and* below K. Why does widening both tails still raise the expected payoff? What happens to paths that end below K?"

**Why this direction:** The question "what happens to paths below K?" is the load-bearing prompt because the floor at zero is the mechanism — once the user names it, the asymmetry follows immediately.
