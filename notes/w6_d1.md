## Concepts introduced

### Classes and encapsulation
- **Member vs local variable:** member belongs to the object (lifetime = object lifetime); local belongs to a function call (lifetime = stack frame).
- **`public` vs `private`:** access control, not copy count. Each object instance has its own copy of every member regardless of access modifier.
- **Member initializer list:** the only place to construct members with arguments. By the time `{}` body opens, members already exist. Syntax: `: _member(arg), _member2(arg1, arg2)`.
- **Encapsulation:** hide implementation (`private`); expose interface (`public`). Swap internals without breaking callers.

### RAII
- Constructor acquires the resource; destructor releases it.
- Value-type members (int, double, mt19937): no heap, no custom destructor needed.
- RAII-type members (std::vector, std::string): own heap but wrap it safely; compiler-generated destructor sufficient.
- Raw pointer members (`double*`): must write custom destructor calling `delete[]`.
- `NormalSampler` has value-type members only — compiler-generated destructor is correct.

### GBM formula
```
S_next = S_current * exp( (r - σ²/2) * dt  +  σ * sqrt(dt) * Z )
```
- Drift term `(r - σ²/2) * dt`: deterministic, same every step.
- Shock term `σ * sqrt(dt) * Z`: random every step (Z ~ N(0,1)).
- σ²/2: log-normal asymmetry correction (same as W4 d1 term).
- sigma=0 check: reduces to `S * exp(r * dt)` — pure risk-free compounding. Verified in output.
