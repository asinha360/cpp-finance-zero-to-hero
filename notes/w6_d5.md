## Concepts landed

### Standard error — what it is

- **SE = stdev / √N** where stdev is the standard deviation of the N individual discounted payoffs.
- Payoff stdev was 14.79 (large, because 44.2% of payoffs are zero and the right tail is fat).
- SE = 14.79 / √100,000 ≈ 0.047 — the standard deviation of the *sample mean* across hypothetical repeated runs.
- Distinction that matters: payoff stdev describes spread of individual paths; SE describes spread of the *average*.
- The "3" in 3×SE comes from the CLT normal distribution: 3-sigma covers 99.73% of outcomes, so a correct pricer fails this test by chance only 0.27% of the time.

### Python visual (run before C++ implementation)

Confirmed numerically:
- Payoff stdev: 14.7899
- SE: 0.0468
- Band: [10.2802, 10.5609]
- BS 10.4502 inside band → test pass
- 44.2% of payoffs exactly zero

### `std::pair<double,double>` — first use

- `price_call()` changed from returning `double` to `std::pair<double,double>`.
- First element: discounted mean payoff (MC price). Second element: discounted stdev.
- Caller uses structured binding: `auto [price, stddev] = mc_pricer.price_call();`
- Qualifying principle applied: caller always needs both values together → return them together.

### One-pass variance formula

```
variance = (sum_sq / N) - (mean * mean)
stdev    = sqrt(variance)
```

- Bug caught: `(p - p) * (p - p)` is always zero — confusion between "square of p" and "deviation from mean." Fix: `p * p`.
- Discounting applied consistently: both mean and stdev scaled by `exp(-r*T)` on return.
