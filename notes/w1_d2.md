## Implementation details

**Compiles clean under:** `g++ -Wall -Wextra -std=c++20`

**Key includes used:**

**Debugger session:** Set breakpoint on the discount line. Observed `PV` variable in the Variables panel showing uninitialised garbage (value approximately `4.179...`) before the line executed, then transitioning to `863.84` after. This was the first live observation of undefined behavior — memory that happened to be at the PV stack address from a prior function call.

## Concepts landed

**Off-by-one in loop:** A hand-written loop was attempted with an off-by-one error. Caught via trace-based coaching (tracing `n=3` by hand). Never made it into the source file. Lesson: trace before you run.

**`std::pow` for exponentiation:** `pow(base, exp)` from `<cmath>`. Not the `^` operator — `^` is bitwise XOR in C++.

**`std::fixed << std::setprecision(2)`:** Controls output formatting. `fixed` means decimal notation (not scientific); `setprecision(2)` means two digits after the decimal point.

**Debugger panel behavior:** The Variables panel in CodeLLDB shows values as they exist in memory at each paused step. Stepping over a line writes the computed value into the variable; before that, you see whatever bytes were there.
